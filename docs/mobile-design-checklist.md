# Mobile design verification checklist

- Safe-area aware fixed controls and bottom navigation
- Minimum practical touch targets for buttons and icon controls
- 16px mobile input/select/textarea text to avoid unintended viewport zoom
- Single-column stacking before tablet breakpoints
- Horizontal overflow retained for data tables
- Bottom-sheet treatment for dialogs on narrow screens
- Mobile-friendly card padding and type scale
- Gold active state with neutral inactive navigation
- Reduced-motion support retained
- Print/PDF styles remain isolated from screen theme changes
